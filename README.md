# Cramer’s Rule — step-by-step guide

Static lesson page that walks through Cramer’s Rule for 2×2 and 3×3 systems. Explanations and worked examples are written in Roman Urdu. It is a reading page, not an interactive solver.

Live: [math-uni.vercel.app](https://math-uni.vercel.app)

## Contents

- Matrix form of a linear system
- Determinants
- 2×2 worked example
- 3×3 worked example
- Verification of the solution

## Stack

Two files only: `index.html` and `style.css`. No JavaScript, no build step, no environment variables.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

## Deploy

Any static host works. The Vercel project points at this repository root.
