Solving Simultaneous Equations using Determinants

Inverse Matrix — 2×2 & 3×3 by Equation
📘

Cramer's Rule Kya Hai?

Cramer's Rule ek method hai jis se hum simultaneous linear equations ko determinants ke zariye solve karte hain. Har variable ki value ek ratio se milti hai:

x = |A₁| / |A|     y = |A₂| / |A|
⚠️ Condition: |A| ≠ 0 hona chahiye, warna system ka unique solution nahi hoga.

Cramer's Rule Apply Karo

Ab formula use karo values nikalne ke liye:

x = |A₁| / |A|     y = |A₂| / |A|

x ki value:

x = |A₁| / |A|
x = −17 / −34
x = 1/2

y ki value:

y = |A₂| / |A|
y = −34 / −34
y = 1
✓

Verification — Jawab Check Karo

Values wapas equations mein daal ke check karo:

Eq (i): 2(1/2) + 3(1) = 1 + 3 = 4 ✅
Eq (ii): 10(1/2) − 2(1) = 5 − 2 = 3 ✅

✨ Final Answer (2×2)

x = 1/2   ,   y = 1

Cramer's Rule — Steps Summary

Step 1: Equations likho
Step 2: Matrix form AX = B banao
Step 3: |A| (coefficient matrix ka determinant) nikalo
